# OneBot 11 签到机器人（Python + Flask + SQLAlchemy + SQLite）

一个由 Flask 驱动的 QQ 群机器人：通过 WebSocket 连接 OneBot 11 服务端，具备前端管理页面，
支持配置群聊白名单、识别群聊用户身份，并处理以 `/` 开头的指令。
内置 `/签到`、`/武器库`、`/购买`、`/出售`、`/转职`、`/晋升`、`/地下城`、`/铁匠铺`、`/锻造`、
`/挑战`、`/踢`、`/撅`、`/佬` 等指令与多级货币体系、职业/晋升/稀有装备、矿石与锻造玩法、
B 站直播/动态监控。

> 📋 版本更新记录见 **[CHANGELOG.md](./CHANGELOG.md)**。

## 功能特性

- **连接 OneBot WS 服务端**：以客户端身份连接 OneBot 的**正向 WebSocket**（主机/端口/路径/授权 Token/消息格式/角色可配置），自动断线重连
- **消息格式**：数组（接收与发送均使用消息段数组格式）
- **角色**：Universal（同一连接同时支持 API 调用与事件推送，路径建议 `/`）
- **群聊白名单**：管理页面可增删/启停白名单群，仅白名单内的 `/` 指令会被处理
- **用户身份识别**：记录群成员的 QQ 号与昵称（优先群名片）
- **命令处理**：消息以 `/` 开头进入命令分发，当前支持：
  - `/签到`：每日签到（每用户每天只能 1 次），随机奖励——
    - **95%** 概率获得 **50~200 铜币**
    - **4%** 概率获得 **888 铜币**
    - **1%** 概率获得 **1 铜币**
    - 连续签到天数会延续（昨日未断则累加）
  - `/余额`：查看当前资产与持有装备数
  - `/背包`：查看持有的武具（按类型分组）与矿石（带稀有度前缀）
  - `/武器库`：查看可购买的装备（按职业与阶级过滤展示；价格档 50→45000 铜币，共 14 档，68 件）
  - `/转职 战士|魔法师`：选择职业（可随时切换）
  - `/晋升`：按地下城进度达标 + 消耗货币提升阶级（解锁更高阶装备）
  - `/购买 商品名 [商品名...]`：消耗铜币购买装备，**支持批量购买**（空格分隔，不能赊账）
  - `/出售 商品名 [商品名...]`：出售装备，获得**购买价 60%** 的铜币，支持批量
  - `/地下城 进入 / 状态 / 退出`：地下城冒险（含 Boss 关掉落，见下文）
  - `/铁匠铺`：查看锻造配方（400 层开启 Lv1，依次开放至 Lv4；锻造从商店 T4.5 之上的毕业线）
  - `/锻造 装备名`：消耗「铜币 + 矿石」制作装备（不能赊账；铁匠铺装备不可回收）
  - `/挑战 @对方`：发起对战，纯随机 50/50 胜负，三条文字演出（间隔 2 秒），赌注结算（见下文）
  - `/boss 列表` / `/boss 挑战 Boss名`：守关 Boss 挑战（普通守关每日共 3 次、大 Boss 1000/2000/3000/3600 每日各 1 次、按装备强度定成功率、首通必出 Boss 材料、大 Boss 额外必掉「万宝源晶」、铜币/稀有永久递减）
  - `/炼金 [配方名]`：查看/制作药水·道具（消耗 材料+矿石+铜币）
  - `/使用 <物品名>`：使用药水（属性 BUFF）/道具（掉落增益）
  - `/踢 @对方` / `/撅 @对方` / `/佬 @对方`：头像合成图片/GIF（见下文）
  - `/帮助`：查看可用命令
- **货币体系**（内部统一以最小单位"铜币"存储）：
  ```
  100 铜币 = 1 银币
  100 银币 = 1 金币
  100 金币 = 1 王国币
  100 王国币 = 1 圣王国币
  ```
- **消息频率限制**（可配置）：按「群 × 用户」统计 "/" 指令频率（如 15 条 / 60 秒），超出后提示「发送消息过快，请在 N 秒后再试」，冷却期内该用户再次发送的消息被静默过滤、不再提示
- **B 站直播间监控**：绑定群号，轮询 B 站公开 API（每 60 秒），直播间开播/下播自动推送到绑定群（开播附封面图）；可配置启用/禁用
- **B 站 UP 主动态监控**：绑定 UP 主 UID 到群号，队列式轮询动态接口（每项间隔 200 秒），检测到新动态自动推送（UP 名/类型/内容/时间/链接，图文动态附配图）；请求层采用 **CDP 真实浏览器优先、curl 降级**的策略抗风控；可配置启用/禁用
- **前端管理页**：连接状态、连接配置、消息频率限制、**直播间监控**、**动态监控**、群白名单管理、用户资产列表、签到记录、**装备库**、**地下城**实时状态、运行日志

## 装备系统（职业 / 武器库 / 晋升）

装备数据保存在 **`equipment.json`**（项目目录内，直接编辑即可维护，程序启动后按文件修改时间自动重载）；
数据库中只记录用户持有的装备 **id**（`user_item` 表），装备完整属性统一从 JSON 读取。

每件装备包含字段：

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一标识（如 `short_sword`） |
| `name` | 名称（如 短剑） |
| `type` | 类型：`weapon` 武器 / `staff` 法杖 / `shield` 盾牌 / `armor` 防具 / `robe` 法袍 / `focus` 法器 / `accessory` 饰品 |
| `line` | 职业线：`physical`（战士）/ `magic`（魔法师）/ `any`（通用） |
| `tier` | 阶级档位（0~5，对应可装备阶级） |
| `attack` / `defense` / `hp` / `mp` / `agility` / `intelligence` | 六维属性 |
| `price` | 标准价格（铜币） |

价格采用**指数式分档**，从 **50 铜币** 涨到 **4 金币 50 银币**（=45000 铜币），共 **68 件**，14 档。
旧「武具店」已改名 **`/武器库`**。

- **职业系统**：`/转职 战士 | 魔法师`
  - 战士（physical）可用：武器/防具/盾牌；魔法师（magic）可用：法杖/法袍/法器（部位对称，不混穿）
  - `any`（通用）仅饰品，两职业共用；未转职：提示先转职；已转职只吃本职业与 `any`，不混搭
  - 另一职业专属装备保留但不生效（背包标注「另一职业·不生效」），可出售
- **晋升系统**：全员一律从 **T0 见习** 起步；`/晋升` 按**历史最高层**达标（50/150/400/800/1600/3200/3600 层）+ 消耗铜币 **逐级**提升阶级（老玩家不自动继承，同样从 T0 逐级晋升）
  - 称号：见习→疾风→烈焰→银辉→苍穹→神谕→灭世→至尊 + 职业名（如「烈焰战士」）
  - **称号提供属性加成**：每阶全属性 **+5%**（T7 封顶 **+35%**），作用于地下城推进/Boss 通关/状态展示——同装备下高阶称号更强
  - 商店（武器库）顶配 T5=45000 随阶级解锁；**铁匠铺按层分级**（Lv1@400 → Lv4@3200）为毕业线，锻造顶级供 T6 灭世 / T7 至尊 追装（不再纯称号）
  - 🏁 **地下城封顶 3600**：通关 3600 层即达成 T7（最高档）；此后不再推进、保留 3600 层驻留，挂机收益（铜币/矿石/材料）持续产出（详见「Boss 挑战 / 材料」节）
- 同价格档 物理武器 与 魔法法杖 **推进收益对齐**（平衡脚本校验 <3%）
- **稀有装备**（Boss 关掉落专属，详见「地下城」节）：商店买不到，背包带 `✦` 与 `(稀有)` 标注；**可出售**（`rare_drops.json` 按 tier 定义参考价，出售得参考价 60%）

- `/购买 商品名 [商品名...]`：消耗铜币购买装备，**支持批量购买**（空格分隔）；**铜币不足无法购买（不能赊账）**；需职业/阶级符合
- `/出售 商品名 [商品名...]`：出售装备，获得购买价 **60%** 铜币（向下取整），支持批量；**铁匠铺锻造的装备无法出售**；**Boss 稀有装备可出售（按 `rare_drops.json` 参考价 60%）**
- 未知商品会给出「你是不是想买：……」的联想提示（按名称/id 包含关系匹配）

## Boss 挑战 / 材料 / 炼金（v2.7）

> 详细数值设计见 `docs/alchemy-boss-consumable-request.md`；Boss 名可整表替换（`bosses.json`）。

- **守关 Boss（/boss）**：18 个命名守关 Boss —— 1000 前每 100 层（100~900）、
  1000「万古魔主·终焉」（究极大 BOSS 单独冠名）、1000 后每 200（1200/1400/1600/1800）、
  2000「万劫魔帝·归墟」（独立命名）、2000 后每 500（2500/3000）、
  3000「万渊魔尊·裂界」（究极大 Boss）、**3600 最终「万瓜之主·夕张」**。
  - 分组与每日额度：**普通守关**（除 1000/2000/3000/3600 外的 14 个）每日组内**共 3 次**（跨 Boss 共享）；
    **大 Boss**（1000/2000/3000/3600）每日**各 1 次**（每 Boss 独立计数）；胜败均扣、按日期重置
  - `/boss 列表`：按历史最高层解锁展示（各 Boss 首通/今日剩余次数）
  - `/boss 挑战 Boss名`：**成功率按当前装备强度**（`S=dungeon_speed(effective_stats)`，
    Logistic 公式，3%~97% 保底/封顶）
  - **掉落**：首通**必出** Boss 材料；重复成功随机 60%（不掉率递减）；铜币/稀有装备随挑战**永久递减**
    （`×max(0.2, 0.8^n)` / `×max(0.1, 0.8^n)`，n=累计成功次数）；稀有 tier ≤ Boss T 档（低级 Boss 只掉低级装）
  - **自动推进首通**：经过命名 Boss 层首次击破 → 必掉 Boss 材料一次（挑战/推进共用首通标记）
  - **3600 最终 Boss 挑战成功**额外掉落 **1 个特殊道具「万瓜圣契」**（`category=souvenir` 独立分类，避免混入 special 随机掉落池；用途暂空、占位收藏）
  - **大 Boss 专属材料**：1000/2000/3000 究极大 Boss 挑战成功**必掉 1 个「万宝源晶」**（`boss_myriad`·神话）；
    3600 最终 Boss 在「万瓜圣契」之外**同样额外掉落**（万宝符原料）
- **材料掉落（地下城）**：
  - 草药 `herb`：普通层 **≥150 层**周期掉落（15 分钟/次，概率 普通35/稀有8/传说随层/神话极小）
  - 特殊物品 `special`：与草药**同池同概率**普通层周期掉落（150 层起每 15 分钟）；Boss 关另有额外 roll（精英 25% / 小Boss 45% / 大Boss 80%）；**神话档掉落「万宝源晶」**（万宝符原料，大 Boss 挑战必掉 + 周期神话档稀有双来源）
  - Boss 材料：`/boss` 挑战与自动推进首通产出（按 Boss T 档共料，同档多 Boss 同材料）；大 Boss 额外掉「万宝源晶」
  - `/背包` 展示材料与药水/道具
- **炼金（/炼金）**：配方消耗 草药/特殊/Boss 材料 + 矿石 + 铜币 → 药水/道具（47 配方，`consumables.json`）
  - **分级解锁**（按配方 Lv × 历史最高层）：Lv1@100 / Lv2@500 / Lv3@900 / Lv4@1300 / Lv5@1700
  - **命名与输入**：等级用阿拉伯数字（「聚财符1」「狂攻药水3」）；「名 1 / 名1 / 名Ⅰ / 名 I / 名一」写法均可匹配
  - **消耗差异化**：同 Lv 六种药水消耗各不相同——为**「草药+特殊」组合、不消耗矿石**（矿石留给锻造，
    避免战士综合缺矿）；草药与特殊材料**同池同概率掉落**（成本由稀有度档唯一决定），
    配方按**材料点数对齐**（common=1 / rare=2 / legendary=3），**同级六种点数一致**（5/6/7/8/9）→ 同级期望成本相同；
    **等效药水（攻=魔、敏=智、防=命）同级用同一种 Boss 材料**，来源等级一致且 ≤ 药水解锁层
    （Lv2=磐岩心核 / Lv3=尸皇骨匣 / Lv4=霜语结晶 / Lv5=烬鳞龙鳞，Lv1 入门不加），全部 Boss 材料均有消耗端；
    道具按增益目标配材料（采掘=矿石/采药=草药/祈灵=特殊/寻宝=Boss 材料/万象=混合/万宝=万宝源晶）
- **使用（/使用）**：
  - 药水 = 属性强化（攻/魔/智/敏 × Lv1~5 **按推进公式权重折算收益等价**：攻=魔=2、敏=智=1.5，故敏智数值=攻魔×4/3；
    防/命为生存乘区属性），加成并入有效属性（提升推进与 Boss 胜率）
  - 道具 = 掉落增益（金钱/装备/矿石/草药/特殊/全材料 × Lv1~3；稀有道具低等级不提供；
    **万宝符1~3 = 全部材料 ×1.6/1.8/2.0**，消耗万宝源晶(1/2/3) + 万宝符3 叠万瓜圣辉，万象符上位）
  - 持续：药水 **持续 100 层**；道具 **持续 4 小时**
  - **互斥覆盖**：药水/道具各自同时仅能存在一种；使用新的药水/道具会替换同类的旧 BUFF 并刷新时长
    （层数型重置为完整 100 层 / 时间型重置为完整 4 小时）；药水与道具互不影响（两槽并存）
  - 查看：`/地下城 状态` 展示生效中的药水/道具及剩余层数/时间（到期自动清理）

## 矿石系统（地下城掉落）

- **解锁资格**：进入地下城时当前层数 **> 400 层** 即获得本轮矿石资格（进入时判定，本轮有效；退出地下城后资格作废，下次进入重新判定）
- **结算周期**：每 **15 分钟**一个结算周期，自动掷骰一次（不足一周期的时间直接丢弃）
- **掉落概率**（按结算时所在层数，**全池掉落、档内随机**）：
  - **普通档 30%**：铜 / 铁 / 锡 / 铅
  - **稀有档 8%**：银 / 秘银 / 精金 / 星辰砂
  - **传说档**：`2% × (层数/400)^0.5`，上限 **30%**（金 / 龙晶 / 圣辉石 / 龙魂晶）
  - **神话档**（极小概率）：`0.1% × (层数/400)^0.5`，上限 **1%**（星陨铁 / 混沌核 / 神谕石）
  - 层数加成只作用于传说/神话档；普通/稀有概率固定
- **矿石种类**（`ores.json`，可直接编辑维护）：共 **15 种**
  | 稀有度 | 矿石 |
  | --- | --- |
  | 普通 | 铜矿石、铁矿石、锡矿石、铅矿石 |
  | 稀有 | 银矿石、秘银矿石、精金矿石、星辰砂 |
  | 传说 | 金矿石、龙晶石、圣辉石、龙魂晶 |
  | 神话 | 星陨铁、混沌核、神谕石 |
- **Boss 关即时掉落**（详见「地下城」）：通关 Boss 层必掉矿石，按 Boss 类型给高稀有占比（大 Boss 高概率神话/传说）
- 数据库（`user_ore` 表）只记录用户持有矿石 **id 与数量**；`/背包` 查看（★神话 / ✦传说 / ◆稀有 / ·普通）
- 矿石的消耗途径：**铁匠铺锻造**（见下节）

## 铁匠铺系统（/铁匠铺、/锻造）

- **解锁条件**：玩家**曾到达地下城 400 层** 开启 **Lv1**（铁匠铺按层分级：Lv1@400 / Lv2@800 / Lv3@1600 / Lv4@3200）；
  锻造产物强度从「商店 T4.5」起步逐级走高，穿戴随铁匠铺 Lv 解锁（不卡当前阶级），商店顶级仍由 T5 玩家购买
- **玩法**：`/铁匠铺` 查看已解锁配方 → `/锻造 装备名` 消耗「**铜币 + 矿石**」制作装备（不能赊账；铜币或矿石不足会明确提示缺什么）
- **配方数据**：`forge.json`（可直接编辑维护），共 **28 个配方**、分 4 个等级，强度从「商店 T4.5」起步逐级走高（Lv1≈商店T4.5 → Lv4≈T7 级毕业带），价格随强度联动（3.2 万铜币起）：

  | 等级 | 价格（铜币） | 每级 7 部位 |
  | --- | --- | --- |
  | Lv1 | 32,000 | 断岳重剑 / 奥术秘杖 / 磐岳战铠 / 灵纹轻袍 / 壁垒圆盾 / 秘仪法器 / 旅者徽记 |
  | Lv2 | 60,000 | 裂空圣剑 / 贤者权杖 / 镇岳重甲 / 星辉法袍 / 辉光方盾 / 曜晶法器 / 贤者指环 |
  | Lv3 | 120,000 | 天罚神剑 / 灭世法杖 / 神鳞圣铠 / 圣辉法袍 / 神鳞重盾 / 神火宝珠 / 神纹圣印 |

  - 每级 7 部位对称齐全：战士武器 / 法师法杖 / 战士防具 / 法师法袍 / 盾 / 法器 / 饰品
  - **锻造消耗因装备而异（差异化矿石组合）**：战士线用金属矿、法师线用魔力矿；
    每级 物理/魔法 所需矿石种类数对等（Lv1~Lv4 = 4/6/8/10 种，累计各 10 种）；饰品可用**全矿物**（Lv4 覆盖全部 15 种矿石）

- 名称支持省略「锻造·」前缀（如 `/锻造 断岳重剑`）；未知配方会给出联想提示

## 对战系统（/挑战）

- **玩法**：`/挑战 @对方`，纯随机 **50/50** 胜负（装备不参与判定），发送 3 条文字演出消息（每条间隔 **2 秒**）：甲出招 → 乙反击 → 终结+胜负结算
- **赌注**：基准 = `max(min(全服资产中位数 × 3%, 双方资产之和 × 10%), 50铜币)`，即「中位数基准」封顶为双方总资产的 10%、保底 50 铜币
  - 挑战方（发起者）败 → 支付 基准 × **1.2**
  - 被挑战方败 → 支付 基准 × **0.8**
  - 赢家通吃；**不能赊账**——输家资产不足时按全部资产支付（资产清零），赢家仅获得输家实际支付的金额
- **次数**：发起方每天限 **3 次**（按日期重置）；被挑战方不限次
- **限制**：不能挑战自己；对方未注册（从未在群里出现过）无法挑战

## 未知指令封禁

- 系统**累计记录每个用户发送的未知指令次数**
- 前 **2 次**：正常提示「未知指令，发送 /帮助 查看可用命令」
- **第 3 次（达到阈值）**：合成 `beat.jpeg` 底图 + 用户头像（46×46 圆形贴 (23,82)）的图片并提示不再响应（合成失败时退回原图）
- **第 4 次起**：该用户的未知指令被**静默过滤**（不提示、不发图），但有效指令不受影响

## 地下城系统

- **进入条件**：持有任意 1 件装备
- **层数进度（幂函数曲线，防数值膨胀）**：第 1 层总进度 **1000**，随时间流逝自动削减，推进速度按【公式】：
  ```
  (攻击力 × 2 + 魔力值 × 2 + 敏捷 × 1.5 + 智力 × 1.5) × (1 + 防御力 / 400) × (1 + 生命值 / 600)
  ```
  每个用户**单独核算**，进度实时持久化，离线/断连期间也按真实时间差补算
- **层难度曲线**（第 n 层总进度）：`1000 × n^0.75`（幂函数，远慢于旧指数曲线，后期不膨胀）
- **金币产出**（按 **5 秒** 为单位核算，未满 1 铜币自动累积）：
  - 第 1 层：每 60 秒 1 铜币
  - 第 n 层每秒产币：`(1/60) × n^0.6`（增速低于难度曲线，更稳健）
- **属性规则**：
  - 初始属性：攻击 5 / 防御 2 / 生命 20 / 魔力 5 / 敏捷 5 / 智力 5
  - **同类型装备只取在【公式】中收益最大的 1 件**（按装备自身属性代入公式计算收益分），不同类型可叠加
  - **职业/阶级过滤**：已转职只吃本职业 + 通用(any)装备；未转职自动择优（物理/魔法取高）；商店/稀有装备 tier>当前阶级的不生效，**锻造装备按铁匠铺 Lv（历史最高层）穿戴、不卡当前阶级**
- **Boss 关**：
  - 分布：每 **10 层精英**、每 **50 层小 Boss**、每 **100 层大 Boss**（同层命中按 大 Boss > 小 Boss > 精英）
  - 血量：Boss 层总进度放大（精英 ×1.5 / 小 Boss ×3 / 大 Boss ×6）
  - **通关掉落**：**额外金钱**（≈当前层产币速率 × 5/15/40 分钟，精英/小Boss/大Boss，随层成长）+
    必掉矿石（按 Boss 类型高稀有占比，大 Boss 高概率神话/传说）+ 概率稀有装备（精英 25% / 小Boss 55% / 大Boss 100%）
- **稀有装备（Boss 掉落专属）**：独立 `rare_drops.json`（41 件，覆盖 T0~T5 全部位），商店（武器库/铁匠铺）**买不到**；
  覆盖 战士主手/盾/防具、法师主手/法器/袍 + 通用饰品；强度介于同阶普通与下一阶普通之间；
  **掉落偏向玩家当前阶级档**（越高级 Boss 越易出该档稀有，低档留保底）；进包立即可见并标 `✦ 名称(稀有) new！`（**仅首次 `/背包` 查看提示**，查看后清除），**退出地下城后下次进入才计入推进速度**
- **矿石掉落**：进入时层数 > 400 层可获得矿石资格（每 15 分钟结算一次，见「矿石系统」）
- **地下城内可用指令**：`/签到`、`/余额`、`/背包`、`/帮助`、`/踢`、`/撅`、`/佬`、`/挑战` 与 `/地下城`（退出/状态），其余指令一律拒绝

## 直播间监控（B 站开播/下播）

- **原理**：批量轮询 B 站公开 API（`getRoomBaseInfo`，无需登录/Token，一次查询所有监控房间），每 **60 秒**一次，检测 `live_status` 变化
- **判定规则**：仅 `live_status == 1`（直播中）视为开播；**轮播（2）不视为开播**
  - `0/2 → 1`：开播通知
  - `1 → 0/2`：下播通知
- **通知内容**：
  - 开播：直播间标题 / 主播名 / 开播时间 / 直播间链接，**附带直播间封面图**（由程序下载到本地后以图片消息发送）
  - 下播：直播间标题 / 主播名
- **绑定规则**：一个群最多绑定 **1** 个直播间；一个直播间可绑定多个群（1 对多）
- **管理**：管理页「直播间监控」卡片可 添加（群号 + 房间号 + 备注）/ 停用 / 启用 / 删除 / 立即检测；卡片内设有**独立监控日志区**（实时显示轮询、开播/下播、增删启停等记录，每 3 秒自动刷新）
- **首次监控**只记录当前状态、不通知，避免误报；网络/接口异常**跳过本轮**、不更新状态
- 备注字段可选（未填时主播名/标题取 B 站接口返回）

## UP 主动态监控（B 站新动态推送）

- **原理**：轮询 B 站公开动态接口（`/x/polymer/web-dynamic/v1/feed/space`），取 UP 主最新动态 id 并与上次记录比对
- **轮询策略**：**队列式串行轮询**——多个 UP 主时逐个轮询、每项间隔 **200 秒**（如 A→200s→B→200s→A…）；仅 1 个 UP 主时每 200 秒一次。拉大单 UP 请求间隔，规避 B 站风控
- **请求层（CDP 优先、curl 降级）**：
  - 优先走 **CDP**：通过 Chrome DevTools 协议驱动本机真实的 Edge/Chrome 浏览器导航到接口地址，请求由真实浏览器内核发出（完整 TLS/JS/环境指纹），并**直接复用 CDP 浏览器里已登录的 B 站登录态**，无需配置 Cookie
  - CDP 不可用时自动**降级为 curl.exe**：系统自带 curl 的 TLS 指纹更接近浏览器，带 Chrome UA + Referer + cookie 文件请求；存在 `bili_cookies.txt`（Netscape 格式）时自动使用其中的登录态（含 SESSDATA），否则自动种入 buvid 系列匿名 Cookie
- **防风控**：命中 B 站风控（-352/412/403 或非 JSON 响应）自动进入 **300 秒冷却**，冷却期间不再请求该接口
- **登录态（Cookie）**：优先复用 CDP 浏览器里已登录的 B 站登录态；无 CDP / CDP 失败时降级用 `curl` 请求，并自动读取模块同目录的 **`bili_cookies.txt`**（Netscape 格式，含 `SESSDATA` 即视为已登录；未注入时 curl 仅携带游客 Cookie，命中风控概率更高）
- **置顶动态处理**：B 站会把置顶动态放在列表最前，代码按真实发布时间 `pub_ts` 倒序排序，以「真正最新的动态」作比对基准，避免置顶挡新动态
- **设计参考**：借鉴 HarukaBot / bili-monitor / bilibili-notify 等开源项目的动态订阅轮询思路（记录最新动态 id 防重复推送）
- **判定规则**：最新动态 id 变化即视为有新动态；一次轮询内出现多条时**按时间从旧到新逐条推送**；「直播了」动态（UP 开播时 B 站自动发的直播动态）不播报（由直播间监控处理开播提醒）
- **通知内容**：UP 主名 / 动态类型（转发/投稿视频/图文/文字/专栏/音频）/ 内容（文字或标题）/ 发布时间 / 动态链接；**图文动态会下载正文配图（最多 3 张）到本地 `tmp/` 后随消息发送**
- **绑定规则**：一个群可绑定**多个** UP 主；一个 UP 主可绑定多个群（多对多）
- **管理**：管理页「动态监控」卡片可 添加（群号 + UP 主 UID + 备注）/ 停用 / 启用 / 删除 / 立即检测；卡片内设有**独立监控日志区**（实时显示轮询、新动态、增删启停等记录，每 3 秒自动刷新）
- **首次监控**只记录最新动态 id、不通知，避免误报历史动态；网络/接口异常跳过本轮、不更新状态

## 使用流程

1. 打开管理页，配置连接并确认"已连接"
2. 在「群聊白名单」中添加目标群号
3. （可选）在「直播间监控」中添加要监控的 B 站房间号并绑定群号，开播/下播自动推送
4. （可选）在「动态监控」中添加要监控的 UP 主 UID 并绑定群号，新动态自动推送（CDP 浏览器登录态优先；无 CDP 时可用 `bili_cookies.txt` 注入登录态 Cookie，见「动态监控」节）
5. 在白名单群里发送：
   - `/签到`：每日签到，随机获得铜币/银币
   - `/转职 战士|魔法师`：选择职业 → `/武器库` 查看可买装备 → `/购买 短剑` → `/出售`
   - `/晋升`：地下城进度达标后提升阶级（解锁更高阶装备）
   - `/地下城 进入`：开始冒险（持有任意 1 件装备）
   - `/地下城 状态`：查看层数/进度/金币
   - `/地下城 退出`：离开地下城（保存进度，下次直达续上）
   - `/铁匠铺`：查看锻造配方（400 层开 Lv1）→ `/锻造 断岳重剑` 消耗铜币+矿石制作
   - `/背包`：查看持有的装备（含 ✦ 稀有）与矿石
   - `/踢 @对方`：合成"踢人"图片（你的头像 + 对方头像贴到底图，30 秒冷却）
   - `/撅 @对方`：合成"撅人"动态 GIF（多帧序列，小概率被反撅，30 秒冷却）
   - `/佬 @对方`：合成"大佬"致敬图（30 秒冷却）
   - `/挑战 @对方`：发起对战（随机 50/50 胜负，每天 3 次）
   - `/余额`：查看资产

## 说明

- 签到日期取服务器本机日期，建议将程序部署在中国时区（UTC+8）机器上
- **复读机**：白名单群里 2 个不同用户发送相同内容的消息后，机器人立刻复读一次；同一轮（60 秒窗口）内即使第 3 个、第 4 个用户继续发相同内容也不再复读，防止刷屏；同一用户重复发送不计入；命令消息（`/` 开头）不参与复读；窗口过期后自动重置
- 地下城进度/金币在任意指令触发时按真实时间差自动补算（惰性结算），无需常驻定时器
- **地下城进度保存**：`/地下城 退出` 会保存当前层数与剩余进度，之后 `/地下城 进入` 会**直达上次位置**继续冒险（例如上次在第 19 层剩 500 进度，下次进入仍从第 19 层剩 500 开始）；无保存进度时从第 1 层开始。管理页地下城表格会显示「保存进度」列；旧数据库首次启动自动补列（无需重建）
