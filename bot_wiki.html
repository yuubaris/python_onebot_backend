⚙️ 装备系统（武器库 / 职业 / 晋升 / 稀有）

装备分职业线（line）与阶级（tier）两条约束：已转职只穿本职业与通用（any）装备，阶级决定能买到/能穿多好的装备。旧「武具店」已改名 /武器库。

职业与可用部位

职业可用类型通用(any)
战士（physical）武器 weapon / 防具 armor / 盾牌 shield饰品（两职业共用）
魔法师（magic）法杖 staff / 法袍 robe / 法器 focus饰品（两职业共用）

部位对称：战士=武器/防具/盾，法师=法杖/法袍/法器（+通用饰品），互不混穿、数量对等。 选择职业：/转职 战士 | 魔法师（可随时切换；另一职业装备保留但不生效，可出售）。未转职先引导转职，地下城自动择优（物理/魔法取高）。

🏁 地下城封顶 3600 层：通关 3600 即达成 T7（最高档）；此后不再推进、保留 3600 层驻留，挂机收益（铜币/矿石/材料）持续产出。

全员一律从 T0 见习 起步；/晋升：历史最高层达标 + 消耗铜币逐级晋升（老玩家不自动继承，同样从 T0 逐级晋升）。称号提供属性加成：每阶全属性 +5%（T7 封顶 +35%），作用于地下城推进/Boss 通关/状态展示——同装备下高阶称号更强。商店（武器库）顶配 T5=45000 随阶级解锁；铁匠铺按层分级（Lv1@400 → Lv4@3200）为毕业线，锻造顶级供 T6 灭世 / T7 至尊 追装（不再纯称号）；武器库同类装备排一起、低于当前阶级也可购（便于换装）。

武器库装备（68 件 / 14 档）

  • 价格档：50 → 45000 铜币（14 档指数递增），每档战士武器 + 法师法杖对称齐全，并有防具/法袍/盾/法器/饰品。
  • 同价格档 物理武器 ≈ 魔法法杖 推进收益对齐（公式收益偏差 <3%，平衡脚本校验）。
  • 部位类型：武器 / 法杖 / 防具 / 法袍 / 盾牌 / 法器 / 饰品；法师中后期也有完整装备链。
  • 出售回收 购买价 60%（稀有装备按参考价 60%）；铁匠铺装备不可出售。

完整装备数值请在游戏内 /武器库 查看（数据源 equipment.json，mtime 热重载）。

稀有装备（Boss 掉落专属，商店买不到）

  • 独立 rare_drops.json（41 件，覆盖 T0~T5 全部位）：战士主手/盾/防具、法师主手/法器/袍、通用饰品。
  • 强度：优于同阶普通、不超过下一阶普通（钳制）；命名独立专属（不与商店/锻造重名）。
  • 掉落偏向：越高级 Boss 越易掉玩家当前阶级档的稀有（大Boss最贴当前档，低档留保底），避免高阶玩家常抽到低阶。
  • 展示：背包/播报带 ✦ 名称(稀有) 与新掉落 new！（仅首次 /背包 查看提示，查看后清除）；进包立即可见，退出地下城后下次进入才计入推进速度。

🏰 地下城

进入条件与限制

  • 持有任意 1 件装备即可进入（/地下城 进入）。
  • 进入后除 /签到、/地下城（退出/状态）、/余额、/背包、/帮助、/踢、/撅、/佬、/挑战、/boss、/炼金、/使用（即时结算，可在地下层内使用）外，其余动作一律拒绝。
  • 退出时保存进度（层数 + 剩余进度），再次进入可直达续上。

初始属性（所有用户一致）

攻击防御生命魔力敏捷智力
5220555

推进公式（核心）

地下城按真实流逝时间自动推进，每个用户独立核算。有效属性 = 初始属性 + 各类型装备中「公式收益最高」的那件属性之和（同类型只取一件，跨类型可叠加）。

推进速度 = (攻击×2 + 魔力×2 + 敏捷×1.5 + 智力×1.5) × (1 + 防御/400) × (1 + 生命/600)
单件装备公式收益分 = (攻×2 + 魔×2 + 敏×1.5 + 智×1.5) × (1 + 防/400) × (1 + 命/600)

职业 / 阶级过滤

  • 已转职：只吃本职业 line + 通用(any) 装备；未转职：自动择优（物理组 / 魔法组取高）。
  • 阶级：只计入 tier ≤ 当前阶级 的装备（tier > 当前阶级不生效）。

难度曲线（防数值膨胀）

第 n 层总进度条采用幂函数，远慢于指数增长：

第 n 层总进度 = 1000 × n^0.75

例：第 1 层 1000、第 10 层 ≈ 5623、第 100 层 ≈ 31623、第 400 层 ≈ 89443。

产币曲线

每秒铜币 = (1/60) × n^0.6　　按 5 秒为单位核算
层数挂机 24h 铜币

产币增速（n^0.6）低于难度曲线（n^0.75），保证后期数值稳健不膨胀。

⛏️ 稀有矿石

地下城 400 层以上、再次进入时获得本轮矿石资格（进入时快照当前层数，本轮有效；退出后资格作废，下次进入重新判定）。

只有「进入时当前层数 > 400」的本轮才会产出矿石；从低层一路挂到 1000 层不产出。

结算周期

每 15 分钟（900 秒）为一个结算周期，挂机时自动掷骰一次。懒结算：不足一个周期的时间余数直接丢弃（如挂 32.5 分钟 = 2 个周期）。

赌注基准（赔率核心参数）

基准 = max( min( 全服资产中位数 × 3% , 双方资产之和 × 10% ), 50 铜币 )
场景支付金额
挑战方 败基准 × 1.2（挑战方自担系数）
被挑战方 败基准 × 0.8
不能赊账：输家资产不足时全部资产支付（最低可降到 0），对方也只能拿到那么多。

示例：全服中位数 10000 → 中位数×3%=300；双方资产各 1000 → 双方和×10%=200 → 基准=min(300,200)=200，再与保底 50 取大 → 200。挑战方败付 200×1.2=240；被挑战方败付 200×0.8=160。
