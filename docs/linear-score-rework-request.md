# 线性收益分体系重构（方案A）· 设计文档

> 状态：**待确认（dry-run）** —— 本文档对应 `docs/regen_linear_score.py` 生成器（dry-run 默认 / `--apply` 生效）。
> 范围：`python_onebot_backend`。本次重构目标是让「收益分」可加、与推进正相关，
> 并用「每档锚定目标分 + 六维凑分」的方式从设计上保证 战士/法师 同档推进一致。

## 〇、dry-run 关键发现（2026-09-08，实测）

方案A 的公平口径 = **同价格档（小阶段）**，而非同 tier。实测暴露商店结构不对称：

1. **只有主手(weapon/staff)每价格档齐全**；armor/robe/shield/focus 是**散放在不同档**的。
   例：T4 战士甲(armor) 只在 ¥26000，而法师袍(robe) 最高只到 ¥15000、法器(focus) ¥15000。
2. 结果：同 tier 满配时 法师总花费 < 战士（T4：法 ¥82k vs 战 ¥104k；T3：¥28k vs ¥36k），
   法师在**更便宜**的前提下推进还曾偏高（旧非线性公式 T4/T5 +17%/+37%）—— 这就是法师偏强的来源之一。
3. 现行 `equipment_balance_check.py` 只校验「同价 weapon≈staff」，**没覆盖 armor/robe、shield/focus 的跨职业同档对位**，
   因此这一结构缺口一直未被发现。

> 结论：仅调数值/公式**不够**——需先让「对称部位落在同一价格档」，才能谈「同档锚定收益分、六维凑分」。
> 生成器 `regen_linear_score.py` 已能给出：每价格档目标收益分表 + 补齐对称部位的 dry-run。

## 〇〇、用户三条口径（2026-09-08 拍板，覆盖上面初稿）

1. **收益分相近即可** —— 不追求逐件/逐档精确相等，同级 3+1 收益分「相近」（约 ±3~5%）即可。
2. **若同级装备数量已对称 → 调整装备价格对齐即可**（T3/T4/T5 各 3 职业件+饰品数量对称；无需新增件）。
   ⚠️ 实测澄清：**价格不参与收益分/推进计算**。法师在新权重下数值本就虚高，
   仅调价格无法让推进相近 → 法师必须**数值下调**；价格仅用于「同强度同价」的观感一致（可选）。
3. **权重对称**：攻击=魔力、敏捷=智力（如 攻=魔=2.0，敏=智=1.5）→ 物理/魔法两线单点价值相等，
   消除旧公式「法师需堆超高智/魔才能对齐」的虚高根源。

### ⚠️ 关键连锁（换公式必须处理，否则校验破）
1. 对称线性公式下，**稀有装备旧钳制会破 16 处**（月蚀/星穹/神陨 的法系、战士坚盾等）
   —— 因为商店/稀有/锻造整套数值原本按旧非线性公式设计；
2. **dungeon_speed 若不改成对称线性**，法师按对称口径下调后真实推进反而偏低（-7%~-18%）
   —— 两套口径不可兼得，必须同步改公式，方案才自洽。

## 一、为什么必须改（现状症结）

### 1.1 旧公式（非线性整套）
```
推进速度 = (攻×2 + 敏×1.5 + 智×1.25 + 魔×1.2) × (1 + 防/400) × (1 + 命/600)
```
- 生存系数是**整套累计**再乘到输出上 → 「单件收益分」与「整套推进」**不可加、不成比例**。
- 法师把 3 个部位(杖/袍/法器)都做成「输出词条」且防/命虚高 → 生存乘区把法师的 off 再放大一遍
  → 实测 T4/T5 法师整套真实推进比战士高 **+16.8% / +36.9%**。
- `item_formula_score` 对纯生存件(防/命)有 `防×2+命×1.2` 的**保底 hack**，与输出件口径不统一，
  导致「凑分」无从谈起（用旧分凑出的同分装备，真实推进并不相同）。

### 1.2 为什么调不动
- 只削法师数值 → 会破坏商店单调 / 稀有钳制 / 职业对位，且每档需要的削幅非线性变化。
- 根因是**结构性**：战士 = 武器(输出)+甲(纯肉)+盾(半输出半肉)；法师 = 杖+袍+法器 三件全输出。

## 二、方案A：线性可加收益分 + 档位锚定凑分

### 2.1 新推进公式（线性可加）
```
推进速度 = 攻×W_A + 敏×W_G + 智×W_I + 魔×W_M + 防×W_D + 命×W_H
        （对「有效属性总和」直接线性加权，无生存乘区、无保底 hack）
```
配套把 `item_formula_score` 改为同一线性公式（同类型取最优仍按它排序）：
```
单件收益分 = 攻×W_A + 敏×W_G + 智×W_I + 魔×W_M + 防×W_D + 命×W_H
```
→ 整套路推进 = 基础分 + Σ(每件生效装备的收益分)，**完全可加**；
→ 「同档装备收益分相同 ⇒ 推进相同」自动成立。

### 2.2 输出词条对称化（消除法师数值虚高的观感问题）
旧公式物理线(攻敏)单点合计 3.5 > 魔法线(智魔) 2.45，导致法师要堆出高得多的智力才能对齐
（如 神谕圣杖 智96 vs 永恒之刃 攻75 —— 玩家长期觉得法师数值虚高）。
本方案让**物理/魔法输出词条每点等值**，数值观感对称：
```
W_A(攻) = 2.0    W_G(敏) = 1.5    物理线
W_I(智) = 2.0    W_M(魔) = 1.5    魔法线（与物理对称）
W_D(防) / W_H(命)：线性标定（默认草案见 §3.3，可调）
```

### 2.3 部位对称 + 每档锚定目标分
两职业 3+1 部位一一对应，同一价格档(p)内给每对「对称部位」同一个目标收益分：
```
主手：weapon(战士) ≡ staff(法师) → T_main(p)
生存：armor(战士) ≡ robe(法师)  → T_surv(p)
副手：shield(战士) ≡ focus(法师) → T_off(p)
通用：accessory 两职业共用        → T_acc(p)
```
只要同档内各对称部位分别凑到相同目标分，则：
```
法师 3+1 总收益分 == 战士 3+1 总收益分  （结构上必然相等）
```

### 2.4 六维凑分（生成器做的事）
给定某部位的目标分 T 与「防/命骨架」后，用整数搜索反推输出词条：
```
剩余分 = T - (防×W_D + 命×W_H)
魔法件：求 (智,魔) 使 智×W_I + 魔×W_M ≈ 剩余分
物理件：求 (攻,敏) 使 攻×W_A + 敏×W_G ≈ 剩余分
```
骨架(防/命)与部位形态（纯肉甲/带输出法袍等）作为参数保留在脚本中，供微调观感。

## 三、关键参数（草案，请在确认前过目）

### 3.1 每档「主手目标分」曲线 T_main(p)
沿用现有 14 档价格并锚定「主手最强、整体平滑递增」；本草案以**旧 3+1 推进在参考点对齐**反推
（标度 K 使 商店 T5 战士满配线性总分 ≈ 旧推进 1596，尽量不改变玩家体感进度），其余档随之平滑。

### 3.2 部位系数（相对主手）
| 部位 | 系数 | 说明 |
|---|---|---|
| 主手 weapon/staff | 1.00 | 输出核心 |
| 生存 armor/robe | ~0.85 | 带部分输出+生存（形态可微调） |
| 副手 shield/focus | ~0.60 | 半输出半生存 |
| 饰品 accessory | ~0.65 | 通用混合 |

> 注：锻造/稀有线沿用同一套线性收益分 + 各自的强度带/钳制基准（见 §4）。

### 3.3 生存词条线性权重（待定）
旧公式防御生命是乘区，无固定「每点分」。线性化草案给出可调起点：
```
W_D(防) = 1.2   每点防御收益分
W_H(命) = 0.7   每点生命收益分
```
含义：1 点防 ≈ 0.6 点攻的收益分（2.0×0.6），1 点命 ≈ 0.35 点攻 —— 保证「堆生存有价值但不碾压输出」。
整体再乘一个总标度 K（见 §3.1）对齐参考点推进绝对值。
