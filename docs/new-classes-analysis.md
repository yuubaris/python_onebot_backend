# 新职业扩展分析：魔剑士 & 近战法师

> 状态：**已落地（v2.12.14，2026-09-09）** · 本文档为落地依据与数值核算
> 目的：评估在现有装备体系（商店/锻造/稀有/Boss 专属 + 统一评分口径）下新增两个混合职业，数值上能否平衡，以及需要哪些配套改动。
> 口径：所有数值来自 `equipment.json / forge.json / rare_drops.json / boss_gear.json` 实际数据 + `dungeon_speed` 权威公式复算（可复现）。

---

## 1. 需求定义

| 新职业 | 定位 | 装备组合（4 槽） | 输出属性 |
|---|---|---|---|
| **魔剑士** | 物理主手 + 魔法施法 | 武器(weapon) + 法器(focus) + 法袍(robe) + 饰品(accessory) | 攻击为主、智力为辅 |
| **近战法师** | 魔法主手 + 物理防护 | 法杖(staff) + 盾牌(shield) + 战甲(armor) + 饰品(accessory) | 魔力为主、敏捷为辅 |

- 不新增装备类型、不新增槽位，全部沿用现有 7 类部位（weapon/staff/shield/focus/armor/robe/accessory）。
- 每个新职业的 4 槽 = 现有战士/法师各取 2 槽交叉组合，**天然复用两职业的专属装备**（见 §5.3）。

## 2. 现有体系速览（新职业的地基）

- **职业线**：`physical`（战士：weapon/armor/shield）、`magic`（法师：staff/robe/focus），`accessory` 通用。
- **推进速度公式**（唯一权威口径，`dungeon.py`）：

  ```
  速度 = (攻×2 + 魔×2 + 敏×1.5 + 智×1.5) × (1 + 防/400) × (1 + 命/600)
  ```

  攻/魔权重对称（2.0）、敏/智对称（1.5）；**防/命是乘法生存乘区，无上限**——装备携带的防/命总量直接放大输出收益。
- **装备评分** = 穿上该件后的推进速度（`item_score`，与推进同一公式）。
- **套装效果（v2.12.1~3）**：穿戴 4 件稀有（可混锻造 2+2）全属性 ×1.1；锻造 4 件 ×1.1；命名 Boss 专属每件 ×1.2 累乘；三大 Boss 专属每件 ×1.5 累乘；3600 专属 ×2。**按件数判定、与职业无关**，新职业同样触发。

## 4. 核心发现：偏差的根源在「生存乘区资源」

新职业的强弱不是公式问题，而是**两条线现有装备的生存属性总量不对等**：

- 推进公式里 防/命 直接进乘法乘区（无上限），高防高命组合会被指数放大；
- 物理线（shield/armor）把大量词条放在 防/命（输出靠攻），魔法线（focus/robe）更多放在 智/魔/命，**防/命总量显著低于物理线**。

实测对比（同档位）：

| 部位 | 物理件（防/命） | 魔法件（防/命） |
|---|---|---|
| 商店 T3 副手 | 镇岳重盾（高防） | 奥术法典（低防） |
| 4 大专属 3000 | 裂界玄铠 304防/336命 | 裂界夜幕 82防/180命 |

因此出现两个方向的偏差：

1. **副手不对等**：商店/稀有档 shield 评分 > focus（T3 差 45 分，约 30%）；锻造 Lv3/Lv4 focus 反超（252→266、318→355）。
2. **组合不对等**：即使单件评分追平（如专属防具 736.8 vs 738.9），物理组合因生存乘区放大，整体仍比魔法组合高 15~25%。

**推论**：魔剑士落在「魔法线强度」（用 focus/robe），近战法师落在「物理线强度」（用 shield/armor）。若维持现状不动数值，**新职业不平衡**（近战法师明显强于魔剑士），且这偏差是现有两线偏差的直接继承——并非新职业引入的新问题。

## 5. 可行性结论与方案

### 5.1 结论

> **能平衡，且可以零新增装备类型落地；但需要先处理两线「生存乘区资源」不对等，否则新职业会继承现有偏差（近战法师 ≈ 战士 > 魔法师 ≈ 魔剑士，差距约 15~25%）。**

### 5.2 三条路径

| 方案 | 做法 | 效果 | 代价 |
|---|---|---|---|
| **A. 接受偏差** | 不调数值，直接落地 | 近战法师偏强、魔剑士偏弱（定位差异，可宣传为"高难职业/速刷职业"） | 数值不严格对等；需接受职业强度梯队 |
| **B. 对齐生存资源（推荐）** | 调整 shield/focus、armor/robe 的 防/命 词条总量，使两条线组合速度相等（延续 v2.12.0「铠甲补攻敏」思路，补齐副手/法袍） | 4 职业（含现有 2 职业）全部对齐，长期最稳 | 会小幅改变现有战士/法师相对强度，需回归测试推进节奏与 Boss 锚定（胜率 70% 口径） |
| **C. 新职业专用补偿** | 不动旧装备，给魔剑士/近战法师隐藏加成 | 可独立调平 | 违背「统一评分口径」，不推荐 |

**建议**：若追求长期平衡 → **方案 B**（一次对齐两线生存资源，4 职业自然平衡）；若想快速上线且接受强度差 → 方案 A 起步，后续再走 B。

### 5.3 装备兼容性（好消息）

| 项目 | 分析 |
|---|---|
| 4 大 Boss 专属 | **正好交叉覆盖**：魔剑士 = 终焉裁决(weapon) + 归墟星瞳(focus) + 裂界夜幕(robe)；近战法师 = 终焉星陨(staff) + 归墟壁垒(shield) + 裂界玄铠(armor)。**无需新增专属装备** |
| 其他 14 命名 Boss 专属 | 覆盖 weapon/staff/shield/focus/armor/robe 全部部位轮换，新职业各取所需 |
| 套装效果 | 按件数判定，新职业混穿 2 稀有+2 锻造 / 专属均正常触发 |
| 商店/铁匠铺购买 | 需在购买限制里把新职业的 types 映射进武器库/铁匠铺（weapon+focus+robe / staff+shield+armor） |

### 5.4 落地影响面清单（未实施，供后续排期）

1. **classes.py**：注册 `spellblade`（魔剑士）/ `battlemage`（近战法师），需引入"双线"概念——现有 `line` 是单值（physical/magic），装备过滤 `_slot_candidates` 按 `item_line in (line, ANY)` 判定，双线职业需改为"line ∈ {physical, magic} 皆可"或 `types` 白名单直接判定。
2. **购买/商店限制**：`class_types()` 决定可买部位，需为新职业配置 type 集合。
3. **未转职自动择优**（`mark_best_equipped`）：现有只在物理/魔法两线间取高，需扩展支持新职业组合。
4. **转职与称号**：称号前缀通用（见习/疾风/…），新职业名接入 `tier_title`；`/转职` 命令加别名。
5. **挑战技能**：现有每职业 3 个娱乐技能（挑战演出文字），新职业需补 3 个（可后续）。
6. **Boss 战力锚定/胜率**：胜率口径按玩家战力 vs Boss 战力，新职业强度对齐后无需改 Boss。
7. **文档**：README/bot_wiki/CHANGELOG + 本分析文档，落地时同步。

## 7. 方案 B 对现有体系的影响评估（2026-09-09 补充核算）

> 结论先行：**方案 B 对 Boss 挑战胜率零影响**；对现有法师是 +15~22% 的绝对增强；对战士完全不动；一步到位让 4 职业（含新职业）组合速度对齐到 ±1%。

> **落地状态（v2.12.8~v2.12.9，2026-09-09）**：用户选定「调整副手」路径后连续落地两批——**v2.12.8 副手（盾/法器）对齐**（商店/锻造/稀有/专属 2000 共 17 组，防/命取较高、输出预算取较高，只增强不削弱，单件评分差 ≤1.2 分）；**v2.12.9 防具（铠甲/法袍）对齐**（同规则 11 组）。实测：Boss 挑战胜率全程 80.4% 零变化；商店全档两线组合 ±1%（T4 1492/1492）、锻造 ±5.5%、4 大专属全穿法师反超 5%（此前落后 21%）；新职业横比同步对齐（魔剑士≈战士线、近战法师≈法师线）。方案 B 已实质完成（除极小的 Lv3 档位取整偏差），新职业落地无需再改现有装备数值。

### 7.1 为什么胜率零影响（已验证）

Boss 胜率口径：`胜率 = x³/(1+x³)`，`x = 玩家速度 S / Boss 基准战力 B0`，而 **B0 按玩家职业 line 从同一装备池锚定**（`named_boss_b0` → `_anchor_combo_s(shop/forge 池, line)` + 称号倍率）。

修改 focus/robe 数值 → 法师玩家的 S **和** 法师线的 B0 **同源同比例上升** → x 恒定 → 胜率不变。

实测（商店 T4 档打 1000 层，穿满同档 + 称号 ×1.2）：

| | 改前 S/B0/胜率 | 补 20 防/40 命后 S/B0/胜率 |
|---|---|---|
| 战士 | 1446.6 / 904.5 / **80.4%** | 1446.6 / 904.5 / **80.4%**（不动） |
| 魔法师 | 1232.5 / 770.7 / **80.4%** | 1449.4 / 906.3 / **80.4%** |

### 7.2 推进速度（挂机/金币/材料收益）：法师 +15~22%

补足 focus/robe 生存词条后，法师组合绝对速度大幅提升（各来源组合对齐战士）：

| 档位 | 法师改前 | 法师改后 | 提升 |
|---|---|---|---|
| 商店 T3 | 774.4 | 929.1 | +20% |
| 商店 T5 | 1257.5 | 1497.4 | +19% |
| 锻造 Lv2 | 1600.4 | 1909.3 | +19% |
| 锻造 Lv4 | 3650.7 | 4468.0 | +22% |

→ 法师玩家的推进、金币、矿石/草药采集全面提速；**战士玩家数值零变化**（不动物理线）。属"白送增强"（已购装备随 JSON 自动生效），公告需说明为两线均衡调整。

### 7.5 落地改动面与连带影响

- **改动**：4 个 JSON（equipment/forge/rare_drops/boss_gear）的 focus/robe 件补防/命，约 30 件，机械改动；**不动公式、不动价格、不动套装、不动掉落**；JSON mtime 缓存免重启生效。
- **连带**：法师装备评分（item_score）整体上升 → 背包/锻造推荐/部位对等展示变化；`/锻造 推荐` 排序可能变化；golden 基线（dungeon_enter/status、forge 等场景）需重新生成并审 diff。
- **风险**：① 法师增强无代价，战士玩家相对优势缩小——发布时需公告说明；② 只补魔法线不动物理线，若未来再调平衡应继续以"生存资源对齐"为统一口径；③ 胜率展示数字不变，玩家可无感过渡。
- **回归**：全量 pytest（60+）→ regenerate golden 审 diff → 三文档 + CHANGELOG 同步 → commit+push main。
