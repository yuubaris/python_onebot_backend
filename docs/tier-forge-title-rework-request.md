## 四、本轮需求 3 —— 称号提供属性加成

**用户原话**：

> 3、称号提供属性加成，同等装备下有称号的实力大于无称号的

**现状**：称号（`_user_title` / `tier_title`）仅作展示；`effective_stats` 只按「装备 tier ≤ 当前阶级」过滤装备，称号本身不加任何属性。T0 与 T7 同装备时地下城推进完全相同。

**要点 / 解读**：
- 需让阶级/称号本身带来属性加成，且**随晋升逐级增强**（这是老玩家从 T0 逐级晋升的核心动力之一）。
- 加成作用于地下城推进（`effective_stats` 输出）；⚠️ `/挑战` 为纯随机 50/50、不参与属性，称号加成不影响挑战。

### 待确认点（3-a）加成幅度与形式

| 方案 | 数值 | 封顶 |
| --- | --- | --- |
| **A（推荐）** | 全属性（攻/防/命/魔/敏/智）每阶 +5% | T7 = +35% |
| B（温和） | 全属性每阶 +3% | T7 = +21% |
| C（只加推进速度） | 每阶地下城推进速度 ×1.05^n | T7 ≈ ×1.41 |

### 待确认点（3-b）作用范围

| 方案 | 说明 |
| --- | --- |
| **A（推荐）** | 地下城推进 / 状态展示 / Boss 通关能力 全部生效（`effective_stats` 一处实现，全链路自动生效） |
| B | 仅地下城推进速度生效 |
| C | 另在 `/余额`/面板文案展示当前称号加成百分比 |
